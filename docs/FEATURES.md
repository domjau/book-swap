# Features & roadmap

## Core
| Feature | Status |
|---|---|
| UI in Lithuanian, Spanish, English; easy to add more | ✅ |
| Book-language filter (separate from UI language) | ✅ |
| Topics: dinosaurs, fairies & magic, animals, space, monsters, funny, bedtime, feelings, learning | ✅ |
| Age groups 0–3, 3–6, 7–9, 10+ | ✅ |
| Search by title / author | ✅ |
| Swap / sell (price) / give away | ✅ |
| Scan ISBN → prefill from own catalogue, Google Books, Open Library | ✅ |
| Search by title when adding | ✅ |
| Manual entry fallback | ✅ |
| 1–4 own photos required (cover and wear), 720 px, metadata stripped | ✅ |
| ISBN shown while looking up and in the found / not found message | ✅ |
| Anti-piracy: chat blocks e-book files and file-sharing links; terms §6a and §11 | ✅ |
| Bundled requests per owner, offer own books in return | ✅ |
| Chat per request, quick replies, accept some or all, decline | ✅ |
| Handover card (date + place), mark handed over | ✅ |
| Reserved / gone status | ✅ |
| Profile stats + badges | ✅ |
| Member reviews: 1–5 little books + comment after a finished exchange (one per person per exchange, editable) | ✅ |
| Profile picture (square, 256 px, metadata removed) | ✅ |
| Sold / donated / exchanged counts on profiles and member pages | ✅ |
| Export / delete my data | ✅ (device only) |
| Terms of use (LT/ES/EN), required at sign-up, re-accept on new version | ✅ |
| Country + postal code at sign-up (format check for common countries), shown on books & members, "Near me" filter, sorted by distance | ✅ |
| Wish list (add by scan / search / manual), matched against shelves | ✅ |
| "From your wish list" and "They want your books" rows | ✅ |
| Member page with tailored offer: their books you want + your books they want, pre-ticked | ✅ |
| "Wanted by …" on your own books, "On your wish list" on others' | ✅ |
| "Books I got" on the profile: books received in finished exchanges (bought / swapped / gift, date), CSV download, nothing about the other member | ✅ |
| Real accounts, shared database, one open network with open sign-up | ✅ |
| In-app notifications (bell) for 10 member types + 2 admin types, chat notifications bundled | ✅ |
| Notification choices per type (app / email) at sign-up and in profile; email right away / daily / never | ✅ |
| Email notifications in the member's language (Edge Function, scheduled) | ✅ (needs setup) |
| Handover reminder the day before | ✅ (needs schedule) |
| Push notifications on the phone | ⚪ |
| Reports with reasons (didn't show up, inappropriate, piracy, spam, safety, other) on chats, listings and members | ✅ |
| Admin panel: stats, announcements to everyone, members (remove, block), reports (read reported chat, hide listing, resolve), admins (add by email, remove), moderation log | ✅ |
| Installable PWA with offline shell | 🟠 (manifest done) |
